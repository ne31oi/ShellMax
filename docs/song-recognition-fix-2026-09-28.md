# Диагностика распознавания пения

Проверен пользовательский MP3 «Lida — Кошка», длительность 120,764 с.
Проверки выполнялись отдельными процессами на CPU. ShellMax, ComfyUI и локальный
ассистент не перезапускались; данные проекта и его сохранённый анализ не изменялись.

## Причина пустого результата

Silero VAD с исходными настройками не нашёл ни одного речевого интервала во всём
треке. При `vad_filter=True` Whisper получал ноль секунд аудио. Это ошибка применения
фильтра обычной речи к пению, а не доказательство отсутствия вокала.

Без VAD первый 30-секундный фрагмент дал одно слово. Разбиение на короткие фрагменты
восстановило часть пропущенного текста. В отдельной пробе 12–24 с распознано 28 слов.

## Изменения

- Для распознавания пения отключён speech VAD; цифровая тишина проверяется отдельно.
- Основные интервалы по 12 с получают по секунде соседнего контекста. Короткий хвост
  менее 3 с присоединяется к последнему интервалу.
- Слова из перекрытия распределяются по времени середины слова. Одинаковый текст
  в разных местах песни сохраняется. Таймкоды остаются относительно исходного файла.
- Язык фиксируется после уверенного автоматического определения (не привязан к русскому).
- Для FFmpeg сохранена обрезка после декодирования. Проверенный вариант быстрого
  входного поиска в этом MP3 искажал начало фрагмента; остальная часть совпадала.
  Непрерывное декодирование FFmpeg совпало с входом диагностических проб PyAV.
- Версия анализатора и ключа кеша повышена до 2. Старый пустой анализ не используется
  при новом запуске анализа обновлённым бэкендом.
- Пустая расшифровка сопровождается пояснением и предложением вставить текст вручную.

## Результат и ограничения

Реальный полный прогон обновлённого анализатора: 170 слов, из них 85 с вероятностью
ниже 0,7. Текст прочитан: остаются ошибки, пропуски и ошибочная подпись музыки в конце.
Количество слов не является оценкой точности. Ошибка пустого результата исправлена,
но достоверная расшифровка этой песни не достигнута. Нужны сверка/вставка правильного
текста; следующим экспериментом для качества может быть распознавание выделенного
вокала. Выделение вокала в этой правке не реализовано и не проверялось.

Полный `uv run pytest -q` после последней правки: 140 passed. Добавлены проверки
сохранения повторов, временного отбора перекрытий, языка, тишины и отмены; сохранены
проверки длинного трека, диапазонов и кеша. Интерфейс не менялся.

Изолированный результат: `data/song_fix_validation_v2/result.json` (игнорируется Git).
Работающий бэкенд продолжает использовать прежний код. Правка вступит в силу при
последующем перезапуске пользователем; затем потребуется повторный анализ трека.
