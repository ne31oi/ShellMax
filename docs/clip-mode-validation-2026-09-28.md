# Режим «Клип»: реализация и проверка

Режим находится в «Ассистент → Клип». Паспорт, музыкальная разметка, обсуждение,
версии блоков, утверждения и история дублей хранятся в SQLite. Изменения паспорта
архивируются; ответы LLM применяются только после проверки схемы и версии проекта.
Бэкенд и собранный интерфейс обновлены, Whisper medium установлен локально.

## Проверки

- `cd backend; uv run pytest -q`: 131 тест прошёл. В этой среде использовался
  отдельный `--basetemp` внутри `data/`, поскольку системный TEMP ограничен песочницей.
- `cd frontend; npm run build`: TypeScript и production-сборка прошли.
- `cd frontend; node --test tests/timeline.test.mjs`: 2 теста прошли — смещения внутри
  перекрывающихся дублей, блокировка пропусков, сохранение ручного монтажа и undo/redo.
- DSP проверен на 490-секундном синтетическом треке с переменным темпом и паузой,
  с началом анализа внутри файла. Для детерминированных проверок слов используется
  подставной ASR; настоящий Whisper medium CPU INT8 отдельно запущен на тестовом тоне.
- Проверены тишина, разные диапазоны кеша, отмена, конфликт версий, частичный ответ
  модели, локальная правка блока и доступность производных FaceRefine/SeedVR2 как дублей.
- Реальный FFmpeg: 20 склеек по 13 кадров, разные разрешения и fps исходников.
  Проверены цвет каждого кадра, точный порядок границ и непрерывность исходного тона.
- В интерфейсе проверены создание клипа, анализ, принятие предложения, автосохранение
  паспорта и восстановление после перезагрузки. Применение постановки и Ctrl+Z вернули
  точный исходный документ таймлайна, включая порядок дорожек и данные дубля.

## Реальный цикл

В отдельном проекте «Проверка режима Клип» локальная Bonsai 2 27B разработала паспорт,
блок 0–2 с, Camera Behavior Card, редакторскую проверку и самостоятельный H3-промпт.
Из интерфейса был запущен один черновой дубль красного бумажного самолёта.

Генерация №102 прошла через текущий профиль «NVFP4 · 10 интервалов». Во время генерации
бэкенд был перезапущен; движок продолжил работу, ID ComfyUI
`cb9b367c-67bb-4ddb-a842-a24923a3927d` сохранился, повторная генерация не создавалась.
Готовый результат подхватился в проект клипа.

Просмотр блока экспортирован в `data/media/montage_0d51aca2.mp4` (медиа №147):
H.264/AAC, 1088×640, 24 fps, 48 кадров, обе дорожки ровно по 2 секунды.
Воспроизведение проверено в интерфейсе; самолёт перемещается слева направо.
Локальная модель отдельно просмотрела три выбранных кадра, технических ошибок не
нашла и отметила спорную стартовую композицию. Это не художественное утверждение дубля.

## Границы проверки

Реальная генерация проверена на одном черновом блоке без людей. Полный музыкальный
клип с пением, липсинк, финальная генерация всех блоков и художественная непрерывность
длинного монтажа в этом прогоне не проверялись. Они требуют пользовательского трека,
референсов и совместного просмотра. Статичная проверка LLM не подтверждает движение.
FaceRefine и SeedVR2 используют прежние диалоги и очередь; повторно физически не запускались.

Существующие воркфлоу, H3-спецификация и параметры локальной LLM не изменялись.
Изменения пользователя сохранены; коммит не создавался.
