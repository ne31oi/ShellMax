## Специфика Claude Code

### Оболочка и долгие процессы

- Среда — Windows. Для скриптов ОС и процессов используй PowerShell, для POSIX-конвейеров — Bash (Git Bash). Не смешивай синтаксис.
- Долгие процессы (бэкенд, установщик) запускай с `run_in_background`, а готовность жди отдельной командой с циклом `until` в фоне. Не жди через `sleep`-опрос.
  Пример: `until curl -s localhost:8710/api/engine | grep -qE '"state":"(ready|external|error)"'; do sleep 1; done`.
- Сквозной прогресс генерации удобнее всего смотреть подпиской на `ws://127.0.0.1:8710/api/ws`: короткий Python-скрипт через `uv run`, фильтр по `type == "generation"`. В ленте есть события `preview` с base64-кадрами, в чат их не выводить.
- Остановить бэкенд: `Get-NetTCPConnection -LocalPort 8710 -State Listen | % { Stop-Process -Id $_.OwningProcess -Force }`. Движок на 8288 при этом продолжит работать, и новый бэкенд его подхватит. Это ожидаемо, движок убивать не нужно.
- `/tmp` в Bash и `/tmp` для Windows-Python — разные каталоги. Временные файлы клади в scratchpad сессии.

### Проверка UI в браузере (claude-in-chrome)

- Вьюпорт у пользователя очень широкий, скриншот сжат, поэтому клики по координатам промахиваются. Кликай по `ref` из `find` / `read_page` или через `javascript_tool`.
- Вкладка автоматизации обычно скрыта (`document.hidden`): Chrome откладывает загрузку `<video>` и троттлит `setInterval`. Чёрный плеер в такой вкладке — не баг.
- Не держи `javascript_tool` в долгом цикле (таймаут CDP 45 с, вкладка «замерзает»). Лучше несколько коротких вызовов.
- После пересборки фронта перезагрузи вкладку. Бэкенд раздаёт `frontend/dist`.
- Тестовые артефакты (генерации, липкое состояние формы) убирай после проверки: `DELETE /api/generations/{id}`, `PUT /api/state/ui {}`.

### Правки файлов

- `.ps1` с кириллицей после Write/Edit должен начинаться с UTF-8 BOM. Проверка: `head -c 3 file | od -An -tx1` → `ef bb bf`.
- Python-вставки через heredoc: в строках с `\n` легко сломать экранирование. Для точечных правок надёжнее Edit.
- Прежде чем говорить «готово», пройди чек-лист из AGENTS.md. Всё непроверенное (например, генерацию без запуска на GPU) прямо называй непроверенным.
