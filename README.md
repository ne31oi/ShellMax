# ShellMax

Локальный видеоредактор, внутри которого работает **собственный** ComfyUI с моделью MiniMax H3.
Генерация повторяет воркфлоу `MiniMax_H3_Singularity_DualSampling_The_AI_Brief_EN` один в один: те же ноды, связи и значения.
При этом вместо графа из 87 нод — простая панель: референсы, описание сцены, несколько чипов и кнопка «Создать».

Сейчас готова студия генерации (этапы 0–2), улучшение лица, детализация SeedVR2, ассистент промптов и базовая склейка на вкладке «Монтаж» (обрезка, разрез, экспорт). Дальше — [этап 4](#дорожная-карта): AI на таймлайне и полноценные мультидорожки.

---

## Возможности

- **Генерация по референсам.** До 9 картинок, 3 видео и 3 аудио. В описании на них ссылаются через `@`: в тексте появляется чип `Picture 1`. Если поменять референсы местами, номера в тексте обновятся сами.
- **Минимум настроек на экране.** Формат, длительность, качество, стиль и подача (look). Остальное — один раз в настройках движка.
- **Черновик раньше финала.** После первого прохода виден черновой ролик. Если он не нравится, финал можно не ждать.
- **Прозрачный прогресс.** Виден текущий этап, номер шага и процент, общий процент и оставшееся время. Точное время каждой готовой генерации сохраняется (и по этапам), а оценки везде — на кнопке «Создать», в «Качестве», в диалоге лица, в оставшемся времени — это среднее по реальным генерациям такого же размера на твоём железе (подсказка показывает, по скольким). Холодные старты с загрузкой моделей в среднее не идут.
- **Повтор в один клик.** «Ещё раз» (новый сид), «Точно» (тот же сид), «Вариации ×4», «Изменить и повторить».
- **Любые модели и LoRA по абсолютному пути.** Файлы моделей не копируются, используются из существующей папки.
- **Стили.** Творческие LoRA добавляются в библиотеку один раз и потом выбираются чипом «Стиль» с силой воздействия.
- **Улучшение лица** (воркфлоу `MiniMax_H3_FaceRefine_Best`). H3 «ломает» мелкие лица на общих планах. Эта функция находит лицо на каждом кадре, перерисовывает его крупным планом по твоему референсу и вклеивает обратно; звук и всё вне лица не меняются. Результат сразу открывается в сравнении «До | После».
- **Детализация (SeedVR2).** Апскейл и восстановление мягких/шумных кадров на готовом клипе (воркфлоу `ShellMax_SeedVR2_Enhance`): масштаб ×1.5 / ×2 / ×3 и пресет согласования цвета. Сравнение «До | После» как у лица.
- **Ассистент промптов** (локальная LLM, как в Minimax Studio V6). Пишешь обычными словами и тегаешь референсы → кнопка «В промпт» переписывает описание в промпт по спецификации MiniMax H3 Singularity. Готовый промпт можно поправить словами («сделай ночь, добавь дождь») кнопкой «Поправить». В диалоге улучшения лица кнопка «Составить ассистентом» пишет промпт крупного плана. В модалке ассистента — экспертные подсказки камеры и света.
- **Медиатека и таймлайн.** Скраб при наведении, A/B-сравнение со шторкой, «кадр → референс». На вкладке «Монтаж»: магнитный таймлайн с обрезкой и разрезом (S), дорожка звука (mute/громкость), превью последовательности и экспорт mp4 в медиатеку.

## Быстрый старт

```bat
scripts\start.bat
```

Что происходит при первом запуске:

1. **Установка движка**, если его ещё нет (`scripts\install_comfy.ps1`). Скачивается официальный ComfyUI portable (~1.8 ГБ), ставятся нужные пакеты нод и ускорители, проверяется, что всё загружается.
2. **Сборка интерфейса** (`npm install` + `npm run build`).
3. **Старт бэкенда.** Он поднимает движок и открывает `http://127.0.0.1:8710`.

Экран приветствия показывает чек-лист: «Движок запущен», «Модели найдены». Если всё зелёное, настраивать ничего не нужно: пути к моделям подставляются автоматически.

> Первая генерация дольше обычной: модели (~50 ГБ) загружаются с диска. Дальше они остаются в памяти.
> При настройках воркфлоу (2 с, 16:9, «Стандарт») генерация занимает около 6 минут на RTX 5060 Ti.

## Как пользоваться

### Панель «Создать видео» (справа)

1. **Референсы.** Перетащи файлы в зону, вставь картинку `Ctrl+V` или перетащи клип из медиатеки.
   - Бейдж на карточке (`Picture 1`, `Video 1`, `Audio 1`) — так модель называет этот референс.
   - Порядок меняется перетаскиванием.
   - У видео есть переключатель 🔊: передавать ли модели его звук. По умолчанию выключен, как в воркфлоу.
   - Оранжевая точка означает, что референс не упомянут в описании.
   - ✂ при наведении на карточку открывает редактор: у картинки — выделить область, у аудио — вырезать фрагмент по волне, у видео — и то и то (▶ проигрывает только выбранный кусок). Оригинал не меняется: «Сбросить» вернёт его. Для видео редактор подскажет, если длина вне 2–15 с.
   - Фотореализм людей — стиль **Realism people** (триггер `r34l1sm.`): включается чипом «Стиль», не в профиле движка.
2. **Описание сцены.**
   - `@` вставляет ссылку на референс.
   - «Шаблон» вставляет каркас `subject_definitions` из воркфлоу.
   - `↑` в пустом поле или кнопка «История» вызывают прошлые промпты.
3. **Чипы:**
   - **Формат** — соотношение сторон;
   - **Длительность** — ползунок прилипает к длинам, которые принимает модель; зелёная зона 5–15 с — диапазон, на котором модель обучалась. Если есть аудио-референс (или видео с 🔊), кнопка «Под Audio N» ставит длину видео по звуку — ближайшую допустимую, не короче звука;
   - **Качество** — Черновик (1088×640), Стандарт (1440×832, как в воркфлоу), Высокое (1920×1088), с оценкой времени;
   - **Стиль** — творческие LoRA;
   - **Подача** — look (кино / реклама и т.п.), влияет на визуальный тон промпта.
4. **Создать** (`Ctrl+Enter`).
   - Рядом кнопка 🎲/🔒: случайный или зафиксированный сид.
   - В меню ▾: число вариантов, профиль движка, сброс к значениям воркфлоу.

Все значения запоминаются между сессиями.

### Медиатека (слева) и вьювер (центр)

- **Щелчок по карточке** — открыть клип во вьювере.
- **Двойной щелчок** — добавить клип в таймлайн.
- **Правый клик** — повторить, вариации, изменить и повторить, в таймлайн, как видео-референс, сравнить, показать в папке, удалить.
- **Во время генерации** вьювер показывает живое превью, текущий этап, шаг и процент. Когда готов черновик, появляется кнопка «Не нравится — остановить»: черновик сохранится.
- **Кнопка 📷 в плеере** добавляет текущий кадр в референсы.
- **Плеер** стартует без звука; выбор запоминается.

### Улучшение лица

Кнопка 🙂 в плеере, пункт «Улучшить лицо…» в меню карточки или «Изменить» у готового улучшения. В диалоге всё заполнено заранее:

- **Чьё лицо** — фото-референс исходного клипа (`<Picture 1>`); можно заменить.
- **Крупный план лица** — рамка на лице (`<Picture 2>`), находится автоматически; её можно двигать и тянуть за углы.
- **Сила** — Бережно / Стандарт (как в воркфлоу) / Сильнее.
- **Если в кадре несколько лиц** — какое улучшать; выбирается один раз и дальше отслеживается.
- **Описание** свёрнуто: по умолчанию шаблон крупного плана с внешностью из исходного промпта (альтернатива — исходный промпт целиком).

Во время работы сначала появляется превью трекинга и сводка («Лицо найдено на 56 из 56 кадров · ~78 px · ×4.5»). Потом лицо перерисовывается, и готовый клип открывается в сравнении «До | После». Модель и LoRA для улучшения, а также его внутренние параметры — в Настройки → Движок → «Улучшение лица». Клипы не на сетке H3 (17k+5 кадров) обрезаются до ближайшей длины; клипы с fps ≠ 24 приводятся к 24.

### Ассистент промптов

- **В промпт** (под полем промпта): опиши сцену обычными словами на любом языке, сошлись на референсы через `@` и нажми кнопку. Текст появляется прямо в поле по мере написания; теги превращаются в чипы. Тост «Вернуть как было» откатывает изменение.
- **Поправить** (появляется вместо «В промпт», когда в поле уже готовый промпт): напиши, что изменить, обычными словами. Ассистент меняет только это, остальной текст и теги референсов остаются. Тот же «Вернуть как было». В диалоге лица кнопка «Поправить» делает то же с промптом крупного плана.
- **Вкладка «Ассистент»** — чат для идей, как в Minimax Studio V6: попроси варианты сцен, выбери номер, попроси промпт — под готовым промптом кнопка «В промпт» отправит его в редактор генерации. Несколько чатов (хранятся на сервере), можно прикрепить картинку для обсуждения (в генерацию она не попадает). Со второго сообщения чата ассистент знает референсы и черновик промпта с вкладки «Генерация»; в новом чате — нет, чтобы не подтягивать чужую тему.
- **Составить ассистентом** (диалог «Улучшить лицо», раздел «Описание»): ассистент смотрит на фото персонажа, рамку крупного плана и кадр клипа, берёт реплики из исходного промпта и пишет промпт крупного плана.
- **Правила**: промпты пишутся строго по спецификации `backend/app/llm/prompt_spec.md` (MiniMax H3 Singularity Video Prompt Writing Specification). Кнопка «Шаблон» вставляет её мастер-шаблон.
- **Модель** — как в студии: Ternary Bonsai 2 27B (PQ2_0 + зрение) на движке PrismML llama.cpp b10709. При первом использовании предлагается скачать (~8,4 ГБ в `llm\`). Альтернативы (Bonsai лёгкая, Gemma 4 12B Q3/Q4/Q5, Qwen3.5 9B) — Настройки → Ассистент.
- **Видеопамять**: ассистент и генерация не работают одновременно. Перед запуском ассистента движок выгружает модели MiniMax; перед генерацией видео ассистент выгружается сам. После 10 минут простоя он выгружается автоматически.

### Настройки (⚙)

- **Движок:**
  - профили (рецепт воркфлоу);
  - пути к модели, энкодеру, VAE и апскейлеру: статус файла, подсказки из папки моделей, выбор через файловый браузер, вставка «Копировать как путь» из Проводника;
  - технические LoRA;
  - «Экономия видеопамяти»;
  - свёрнутый раздел **«Эксперт»** (шаги, сэмплер, планировщик, sparse attention и др.) с кнопкой «Сбросить к воркфлоу».
- **Стили:** библиотека творческих LoRA. Их можно добавить по пути или одним кликом из найденных в папке моделей. Для каждой задаются сила по умолчанию и слова-триггеры.
- **Система:** состояние и лог движка, запуск / перезапуск / остановка, уведомления.

## Движок

```powershell
powershell -ExecutionPolicy Bypass -File scripts\install_comfy.ps1 [-WithDebugNodes] [-SkipVerify]
```

- Ядро: ComfyUI **v0.37.0**, коммит `b0f4b7b`, тот же, на котором воркфлоу проверен в основной установке.
- Пакеты нод на пиннутых коммитах:
  - [ComfyUI-KJNodes](https://github.com/kijai/ComfyUI-KJNodes) — Sage attention, LowVRAM, ChunkFeedForward;
  - [ComfyUI-VideoHelperSuite](https://github.com/Kosinkadink/ComfyUI-VideoHelperSuite) — загрузка и сборка видео;
  - [Comfyui_Minimax_h3_latent_Upscaler](https://github.com/LBH-123-AI/Comfyui_Minimax_h3_latent_Upscaler) — латентный апскейл;
  - [ComfyUI-H3-FaceRefine](https://github.com/Carasibana/ComfyUI-H3-FaceRefine) — трекинг, кроп и вклейка лица;
  - [comfyui-obvpm](https://github.com/obvpm/comfyui-obvpm) — «Load Image & Crop» для крупного плана;
  - `comfy_nodes/h3_native_audio_lock` — «замок аудио» для липсинка (копия локального пакета из основной установки).
- Для улучшения лица: детектор `ultralytics/bbox/face_yolov8m.pt` берётся из общей папки моделей, insightface `buffalo_l` копируется в движок (~300 МБ), `onnxruntime-gpu`.
- Ускорители: `triton-windows`, `sageattention`, `comfy-kitchen` (sol-attn). Установщик проверяет, что sol-attn доступен для видеокарты.
- Модели подключаются через `extra_model_paths.yaml`, без копирования.
- `-WithDebugNodes` дополнительно ставит rgthree и Easy-Use, чтобы оригинальный воркфлоу открывался в интерфейсе движка (`http://127.0.0.1:8288`).

Скрипт идемпотентный: повторный запуск пропускает готовые шаги. Движок переживает перезапуск ShellMax: бэкенд находит его по PID и берёт под управление, модели остаются в памяти.

## NVFP4 DualSampling

Дополнительный режим использует INT8 на первом проходе и отдельную смешанную NVFP4-модель на финальном. Основной профиль Singularity остаётся прежним. Профиль для запуска выбирается в меню у кнопки «Создать»; пути и рецепт — в Настройки → Движок.

Доступны «NVFP4 · 10 интервалов» (ближе к эталону №76) и «NVFP4 · 5 интервалов» (быстрее, сильнее меняет движение). Число означает интервалы финального прохода; первый INT8-проход одинаковый. Оба используют одну модель `data/models/singularity_nvfp4_fc1_middle30.safetensors`, автоматически из интернета она не скачивается. Для сравнения с №76 нужен стиль Realism people с силой 1.0. У быстрого профиля сохраняйте экспертные значения: шаги 6, расширение 2, разделение 2. Результаты и ограничения: [исследование NVFP4](docs/nvfp4-research-2026-09-27.md).

## Решение проблем

| Симптом | Что делать |
|---|---|
| «Движок не установлен» | Запустить `scripts\install_comfy.ps1` (или просто `start.bat`) |
| «Ошибка движка» при старте | Настройки → Система → лог. Частая причина — старый драйвер NVIDIA |
| «На порту работает другой ComfyUI» | На 8288 работает чужой процесс: закрыть его или сменить порт в `config\comfy.json` |
| «Не хватило видеопамяти» | Кнопки на экране ошибки: «Снизить качество» или «Включить экономию VRAM и повторить». Не запускать одновременно основной ComfyUI |
| «Не найдены файлы моделей» | Настройки → Движок: красные точки у полей. Указать путь или выбрать файл |
| Повтор с тем же сидом немного отличается | Это нормально: sage- и sparse-attention на GPU не бит-в-бит детерминированы |

## Разработка

Правила, архитектура и подводные камни описаны в [AGENTS.md](AGENTS.md).

```bat
cd backend  && uv run pytest              :: тесты (включая сверку графа с воркфлоу)
cd backend  && uv run python -m app.main  :: API и собранный интерфейс на :8710
cd frontend && npm run dev                :: интерфейс с hot reload на :5173 (прокси на :8710)
cd frontend && npm run build              :: проверка типов + сборка в frontend\dist
```
